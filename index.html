Services

Work That Makes An Impact

Four areas I own end-to-end. Each one has a metric, a gate, and a rollback path. From training to serving, from GPUs to the bill, feel free to reach out!

ML Platform & Lifecycle

Data quality gate at the entrance, versioning for data and models (DVC, MLflow), behavioral metrics as the deploy gate, drift detection and retraining triggers. Every model is traceable to the code, data and config that produced it.

Inference Infrastructure & Cost

Triton, KServe, TensorRT on Kubernetes: canary with quality-based auto-rollback, scale-to-zero, dynamic batching. Cost per inference unit is a design metric, not a cleanup task for later.

Distributed Video ML

Queue-coordinated GPU workers, backpressure, idempotency, exactly-once vs at-least-once. Ray Data shards video, Dagster orchestrates ingest → preprocess → infer → annotate with lineage and retry.

Platform, GitOps & Observability

Kubernetes (EKS), ArgoCD, Terraform, Istio. Prometheus, Grafana, Loki, OpenTelemetry all the way down to model quality. Deploy is a commit, rollback is a revert, no manual operations on production.
